# Lab 4 — Lập trình hướng đối tượng trong Python

Thư mục này gồm bốn bài thực hành theo đề Lab4_PP_OOP.docx:

- `ex01_country_class.py`: lớp `Country`, kiểm tra dữ liệu, mật độ dân số, so sánh diện tích, `__str__` và `__repr__`.
- `ex02_continent_composition.py`: quan hệ hợp thành `Continent` chứa `Country`, thống kê dân số/diện tích và quốc gia lớn nhất.
- `ex03_encapsulation_nematode.py`: thuộc tính private, getter/setter có kiểm tra, tăng trưởng và name mangling.
- `ex04_academic_inheritance.py`: `Member`, `Student`, `Faculty`, kế thừa với `super()`, overriding, đa hình và MRO.

Chạy từng bài từ thư mục dự án, ví dụ:

```powershell
python .\ch3-oop\ex01_country_class.py
python .\ch3-oop\ex02_continent_composition.py
python .\ch3-oop\ex03_encapsulation_nematode.py
python .\ch3-oop\ex04_academic_inheritance.py
```

Bài 3.2 import `Country` từ file bài 3.1. Python 3.10 trở lên được khuyến nghị.
